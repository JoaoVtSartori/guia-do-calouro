# guia-do-calouro
Projeto colaborativo desenvolvido para ajudar novos alunos a conhecerem melhor a escola, sua estrutura, suas regras e as atividades disponíveis.

## Seções do guia
As informações serão organizadas nas seguintes seções:
1- Horários |
2- Mapa da escola |
3- Dicas de estudo |
4- Regras de convivência |
5- Clubes e atividades |
6- Contatos úteis da escola |
